# 🎰 천재 수학자의 로또 번호 추천 시스템

**"천재들의 사고방식으로 행운을 계산하다"**

피보나치, 파스칼, 페르마의 천재적인 수학 이론을 기반으로 로또 번호를 추천하는 AI 시스템입니다.

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Streamlit](https://img.shields.io/badge/Streamlit-1.29+-red.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

## 📋 프로젝트 개요

이 시스템은 단순한 랜덤 번호 생성기가 아닙니다. 세 명의 위대한 수학자의 이론을 활용하여 과학적이고 체계적으로 로또 번호를 분석하고 추천합니다.

### 🧠 세 천재의 이론

1. **🟡 레오나르도 피보나치** (1170-1250)
   - 피보나치 수열과 황금비율(φ ≈ 1.618)
   - 자연의 성장 패턴과 조화로운 비율

2. **🔵 블레즈 파스칼** (1623-1662)
   - 파스칼 삼각형과 조합론
   - 확률론과 이항분포, 기댓값 계산

3. **🟢 피에르 드 페르마** (1607-1665)
   - 페르마 소정리와 소수론
   - 완전제곱수와 거듭제곱 관계

## ✨ 주요 기능

### 1. 데이터 수집
- 동행복권 API로부터 1~1194회차 자동 수집
- 로컬 캐싱으로 빠른 재사용
- 실시간 진행률 표시

### 2. 5가지 추천 알고리즘
각 알고리즘은 수학자의 사고방식을 반영합니다:

- **피보나치 수열**: 황금비와 자연의 패턴
- **파스칼 조합론**: 조합 계수와 동반 출현 분석
- **파스칼 확률론**: 이항분포와 기댓값 최적화
- **페르마 소수론**: 소수의 특별한 성질
- **페르마 거듭제곱**: 완전제곱수의 관계 패턴

### 3. 통계 분석
- 번호별 출현 빈도 차트
- 홀짝/고저 비율 분석
- 구간별 분포 (1-15, 16-30, 31-45)
- 연속 번호 출현 패턴
- 최근 트렌드 시각화

### 4. 수학적 배경 설명
- 각 이론의 상세 설명
- 인터랙티브 시각화
- 로또 적용 방법론

## 🚀 설치 및 실행

### 1. 저장소 클론
```bash
git clone https://github.com/shirtgit/lotto2.git
cd lotto2
```

### 2. 가상환경 생성 (권장)
```bash
python -m venv venv
venv\Scripts\activate  # Windows
# source venv/bin/activate  # Mac/Linux
```

### 3. 필요한 패키지 설치
```bash
pip install -r requirements.txt
```

### 4. 애플리케이션 실행
```bash
streamlit run app.py
```

브라우저가 자동으로 열리며 `http://localhost:8501`에서 앱을 확인할 수 있습니다.

## 🎨 사용 방법

### 1단계: 데이터 수집
1. 사이드바에서 "🔄 데이터 수집/업데이트" 버튼 클릭
2. 1~1194회차 데이터 자동 수집 (최초 1회만)
3. 이후에는 캐시된 데이터 자동 로드

### 2단계: 번호 추천 받기
1. "🎲 추천 번호" 탭 선택
2. "✨ 번호 생성하기" 버튼 클릭
3. 5개 세트의 추천 번호 확인
4. 각 번호의 수학적 근거 읽기

### 3단계: 통계 분석
1. "📊 통계 분석" 탭 선택
2. 분석 범위 선택 (전체/최근 50회/최근 100회)
3. 다양한 차트와 통계 확인

### 4단계: 이론 학습
1. "📚 수학적 배경" 탭 선택
2. 각 수학자의 이론 이해
3. 적용 방법론 학습
